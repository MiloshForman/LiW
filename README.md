# LiW
### LiW - сокращение от "look in your wallet" (загляни в свой кошелек) - фича для личного кабинета клиента банка: виджет, который показывает несколько последних успешных банковских операций клиента.
## Можно установить:
### командами в терминале из PyCharm:
#### git clone git@github.com:MiloshForman/LiW.git
#### poetry install
## Функционал
### На данный момент проект находится на стадии разработки и работоспособность уже существующих функций можно проверить из модуля main.py.
## mask_account_card
### функция mask_account_card принимает тип-номер карты или счета и возвращает замаскированный номер. Для демонстрации присвойте переменной card_name имя и номер карточки или номер счета, например: card_name = 'Visa Platinum 7000792289606361', или card_name = 'Счет 73654108430135874305'.
### запустите модуль, и терминал выдаст маску карты либо счета.
## get_date
### функция get_date принимает на вход строку и отдает корректный результат в формате 'ДД.ММ.ГГГГ'
### присвойте переменной long_date дату например long_date = '2024-03-11T02:26:18.671407'
### при запуске модуля терминал выдаст дату нужного формата: 11-03-2024
## filter_by_state
### функция filter_by_state принимает список словарей со значением ключа state, и возвращает список со словарями, у которых ключ соответствует указанному значению.
### присвойте переменной source_list список словарей и значение ключа state. Терминал выдаст список словарей с указанным ключом.
## sort_by_date
### функция sort_by_date принимает список словарей и возвращает список, отсортированный по дате в нужном порядке.
### присвойте переменной source_list список словарей и порядок сортировки. Терминал выдаст отсортированный в нужном порядке список.
